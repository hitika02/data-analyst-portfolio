# Data Analyst Portfolio — Hitika Gupta

Five end-to-end data analysis projects built with **Excel, SQL, Python, and Power BI** —
the tools used daily in data analyst roles. Each project starts from a business
question, works with realistic messy data, and ends with documented findings and
a recommendation.

| # | Project | Skills demonstrated | Business question |
|---|---|---|---|
| 1 | [Retail Master Data Quality Audit](01-retail-master-data-quality/) | Python, SQL validation | Can we trust the product master file? |
| 2 | [E-commerce Sales Dashboard](02-ecommerce-sales-dashboard/) | Power BI, DAX | What's driving sales performance? |
| 3 | [SQL Customer & Product Analysis](03-sql-customer-product-analysis/) | SQL (joins, window functions) | Who buys, what sells, do they return? |
| 4 | [Marketing Campaign Performance](04-marketing-campaign-performance/) | Excel, funnel metrics | Which marketing channel earns its budget? |
| 5 | [Inventory & Stock Analytics](05-inventory-stock-analytics/) | Excel, SQL reporting | Where are we risking stockouts or trapping cash? |

## How to use this portfolio
- Each folder is **self-contained** — it can be pushed as its own GitHub
  repository, or you can push this whole portfolio as one repo.
- Every README states the business problem, the method, the **real findings**,
  and how to reproduce the work.
- Datasets are synthetic (generated for portfolio use); all analyses, metrics,
  and findings are genuine computations on that data.

## Suggested GitHub setup
- **Option A (recommended):** 5 separate repos, one per project — looks stronger
  on a profile and lets you link the most relevant project per job application.
- **Option B:** 1 repo (`data-analyst-portfolio`) with 5 folders — simpler to maintain.
